# Fake Review Detector

Live Project Link --> https://fake-review-detector2.streamlit.app/

A machine learning web application built using:

- Python
- Pandas
- Scikit-Learn
- TF-IDF Vectorization
- Logistic Regression
- Streamlit

The model was trained on 40,000+ reviews and predicts the review category along with a confidence score.

## Run Locally

pip install -r requirements.txt

streamlit run app.py
